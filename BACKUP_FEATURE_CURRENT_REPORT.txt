New page

/backups

Report periods
--------------

- Selected month
- Current month live
- Calendar year
- Financial year

Role permissions
----------------
Admin: Complete/IT/Drone Excel, save server backups, download database/MinIO/manifest files
Management: Complete/IT/Drone Excel downloads
IT: IT Excel downloads only
Drone: Drone Excel downloads only

Automatic cPanel schedule
-------------------------
Daily: complete Excel + PostgreSQL dump + current-month Excel
First day of month: previous-month frozen Excel
January 1: previous calendar-year Excel
April 1: previous financial-year Excel

Storage
-------
Docker/local default: <project-parent>/NAKSHA_BACKUPS
cPanel recommended: /home/<cpanel-user>/nakshatech_backups
Never store recovery dumps under public_html.

Safety
------
Excel is the readable operational copy.
PostgreSQL custom-format dump is the disaster-recovery source.
Restore requires a command-line confirmation and is never automatic.
