# Light Enterprise Asset Management Theme

## Scope

This release changes only the authenticated frontend presentation. It applies a unified light enterprise workspace to Admin, Management, IT and Drone pages while retaining the approved dark Welcome and Login pages.

## Visual direction

- Dark navy corporate sidebar
- Soft white and light-blue workspace
- Cyan-to-blue primary actions
- White cards with thin blue-grey borders
- Clean enterprise tables, filters and forms
- Meaningful status colours only
- Low-opacity geospatial watermark in internal page headers
- Responsive sidebar drawer and horizontally scrollable tables

## Files changed

- `frontend/src/styles.css`
- `frontend/src/components/Layout.tsx`

## Functionality preserved

No backend, API, database, authentication, route, payload, Excel, role-permission or business-workflow file was changed. WelcomePage, LoginPage and App routes remain byte-for-byte unchanged from the uploaded source.

## Theme coverage

- Admin overview and module cards
- Management dashboard
- IT Dashboard, Asset Register, Work Records, Replacements and Reports
- Drone Dashboard, Assets, Kits, Projects, Operations, Work Records, Movements and Import
- Shared sidebar, top header, buttons, forms, tables, filters, cards, badges, empty states and responsive layouts
