Frontend build limitation in this environment
---------------------------------------------
The full npm/Vite production build could not be run because the available internal npm registry returned 404 for @types/react@18.3.18. The TypeScript/TSX source was syntax-parsed successfully. The included Docker/Windows apply script performs the real build on the deployment machine.

Deployment safety
-----------------
- No docker compose down -v command is used.
- Existing PostgreSQL, Redis and MinIO volumes are preserved.
- Backup writes are atomic.
- Overlapping backup runs are locked.
- Database restore is not exposed in the browser.
- Backup paths are restricted to BACKUP_ROOT.
- cPanel backup folder is documented outside public_html.

Important cPanel condition
--------------------------
The backup scheduler is cPanel Cron compatible. Full application parity on shared cPanel still requires the hosting provider to support the FastAPI/ASGI runtime, WebSockets, PostgreSQL, Redis and MinIO/external equivalents. The backup feature does not remove those hosting requirements.
