# NakshaTech Welcome Page Integration

## Final workflow

- `/` opens the responsive NakshaTech welcome page when the user is signed out.
- The header Login button and the main Login button both open `/login`.
- Existing authentication remains unchanged.
- A signed-in user who opens `/` is redirected to the correct role dashboard.
- All protected application routes remain unchanged.

## Visual design

- Dark cinematic geospatial world-map background.
- Official NakshaTech horizontal logo lockup.
- “Smart Internal Asset Management” headline.
- Minimal description and two clear Login entry points.
- Desktop composition closely follows the approved reference.
- Mobile layout uses a glassmorphism content panel for readability.

## Responsive validation sizes

- 1440 x 900 desktop
- 1366 x 768 laptop
- 390 x 844 mobile
- 360 x 800 small mobile

The tested layouts produced no horizontal or vertical page overflow at the specified viewport sizes.
