NAKSHA TECH ASSET MANAGEMENT - CLEAN LOCAL MASTER

THIS IS THE FOLDER TO USE FROM NOW ON.
Do not mix it with the old cPanel builder, crm_backend, or previous asset-management-system folders.

FIRST RUN ON WINDOWS
1. Install and start Docker Desktop.
2. Extract this ZIP to:
   E:\NakshaTech_Asset_Management_Local_Master
3. Double-click:
   SETUP_AND_START_LOCAL_WINDOWS.cmd
4. Enter the local Admin email/password when requested.
5. Open:
   http://localhost:3100

NORMAL DAILY START
  Double-click START_LOCAL_WINDOWS.cmd

STOP
  Double-click STOP_LOCAL_WINDOWS.cmd

AFTER CODE CHANGES
  Double-click REBUILD_LOCAL_WINDOWS.cmd
  Then press Ctrl+Shift+R in Chrome.

LOCAL URLS
  Frontend:      http://localhost:3100
  Unified app:   http://localhost:8088
  Backend API:   http://localhost:8100
  API Docs:      http://localhost:8100/docs
  MinIO Console: http://localhost:9005

SOURCE CODE
  Frontend: frontend\src
  Backend:  backend\app
  Docker:   docker-compose.yml

IMPORTANT
- .env and LOCAL_LOGIN_CREDENTIALS.txt are local-only and must not be uploaded.
- The current secure login page has blank email/password fields and no automatic role login.
- User roles are selected by the backend account.
- This package does not change or connect to the cPanel production database.
- RESET_FRESH_LOCAL_DATA_WINDOWS.cmd deletes only this package's local Docker data.
